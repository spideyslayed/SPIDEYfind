# VistaFind

VistaFind is a plain HTML, CSS, and JavaScript image-search app that will let users search for a topic and browse matching images in a responsive gallery.

I chose a dark navy and amber colour theme to give the app its own visual identity instead of copying the PixelPulse reference.

I added quick-pick topic chips so users can easily discover common search ideas.

I also added a Clear button and an empty-state message to make the search interface easier to understand and use.

Search functionality will be added in Part 2.
